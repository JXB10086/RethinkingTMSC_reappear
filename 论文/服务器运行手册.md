# RethinkingTMSC 服务器运行手册（详细版）

> 服务器：`connect.nmb1.seetacloud.com` 端口 `10689`，用户 `root`
> 环境：RTX 4090，conda 环境 `tmsc`（Python 3.10 + torch 2.1.2 + transformers 4.22.1）

## 一、连接服务器

### 方式 1：命令行 SSH（Windows PowerShell / macOS / Linux 通用）

```bash
ssh -p 10689 root@connect.nmb1.seetacloud.com
```

回车后输入密码即可（或使用密钥：`ssh -p 10689 -i 私钥路径 root@connect.nmb1.seetacloud.com`）。
登录成功后命令行提示符会变成 `root@autodl-container-...:~#` 之类。

### 方式 2：VS Code 远程开发（推荐，方便看文件）

1. 安装扩展：`Remote - SSH`；
2. `Ctrl+Shift+P` → 输入 `Remote-SSH: Connect to Host...` → `+ Add New SSH Host...`；
3. 粘贴：`ssh root@connect.nmb1.seetacloud.com -p 10689`；
4. 选择保存位置后连接，输密码；
5. 连上后：`文件 → 打开文件夹 → /root/RethinkingTMSC`；
6. 菜单 `终端 → 新建终端` 即可执行命令。

## 四、手动跑一组实验（核心操作）

### 第 1 步：进入项目并设置环境变量

```bash
cd /root/RethinkingTMSC
export PATH=/root/miniconda3/envs/tmsc/bin:$PATH
export PYTHONPATH=/root/RethinkingTMSC
```

> 注意：`PYTHONPATH` 必须设置，否则会报 `No module named 'Code'`。

### 第 2 步：确认 python 用的是 tmsc 环境

```bash
which python
python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
```

应输出 `torch 2.1.2+cu118 True`。

### 第 3 步：运行单个模型

以“Twitter15 上的 Bert，种子 0”为例：

```bash
python Code/training/run_data_analysis.py \
  --data_dir data/Twitter15 \
  --task_name Twitter15 \
  --output_dir /autodl-fs/data/RethinkingTMSC_output/Twitter15/Bert/0_output_test \
  --learning_rate 2e-5 \
  --seed 0 \
  --test_file test.tsv \
  --bert_model bert-base-uncased \
  --encoder resnet \
  --do_train --do_eval \
  --train_batch_size 32 \
  --mm_model Bert \
  --num_train_epochs 8.0 \
  --resnet_root /root/RethinkingTMSC/Code/resnet
```

### 参数解释

| 参数 | 说明 | 取值 |
| --- | --- | --- |
| `--data_dir` / `--task_name` | 数据集 | `data/Twitter15` / `Twitter15`；`data/Twitter17` / `Twitter17` |
| `--output_dir` | 结果保存位置 | 建议放在共享盘 `/autodl-fs/data/RethinkingTMSC_output/...` |
| `--seed` | 随机种子 | 0、42、199、2022、11122 |
| `--encoder` | 图像编码器类型 | `resnet` / `vit` / `faster`（faster 当前不可用） |
| `--mm_model` | 模型名 | 见下表 |
| `--num_train_epochs` | 训练轮数 | 8.0 |
| `--learning_rate` | 学习率 | 2e-5 |
| `--train_batch_size` | 批大小 | 32 |
| `--resnet_root` | ResNet-152 权重目录 | `/root/RethinkingTMSC/Code/resnet` |

### 模型名与 encoder 对照表

| encoder | 模型名 |
| --- | --- |
| `resnet` | Bert、ResNet、ResBert、ResBertTFN、Res2Bert、Bert2Res、Res22Bert、ResBertAtt |
| `vit` | Vit、VitBert、VitBertTFN、Vit2Bert、Bert2Vit、Vit22Bert、VitBertAtt |
| `faster`（暂不可用） | FasterRCNN、FasterBert、FasterBertTFN、Faster2Bert、Bert2Faster、Faster22Bert、FasterBertAtt |

### 运行过程中的正常现象

- 前 1–3 分钟 GPU 可能是 0%，在 CPU 上做图片特征转换（提示 `the number of problematic samples` 等），正常；
- 然后日志出现 `Iteration: ... it/s`，GPU 开始吃满；
- 每轮结束出现 `***** Running evaluation on Dev Set*****` 和 dev 结果；
- 训练结束输出 `eval_results.txt / pred.txt / true.txt`。

## 五、批量运行（150 组或指定模型）

### 续跑 / 全量

```bash
cd /root/RethinkingTMSC
bash /root/run_server.sh
```

`run_server.sh` 已内置：15 个可用模型、输出到 `/autodl-fs/data/RethinkingTMSC_output`、
后台运行（nohup）。**已有 `eval_results.txt` 的组会自动跳过**（断点续跑）。

### 只跑部分模型

```bash
MODELS="Bert Res22Bert Bert2Vit" bash /root/run_server.sh
```

### 双卡并行（如果以后有多卡）

```bash
DEVICES=0,1 bash /root/run_server.sh
```

> 警告：如果当前已经有一份 `run_all.sh` 在跑，**不要**再启动第二个，会互相冲突。
> 先确认没有在跑（见第三节），或者等它结束。

## 六、停止 / 重跑

### 停止全部训练

```bash
pkill -f run_data_analysis.py
pkill -f run_all.sh
```

### 重跑某一组（先删结果再跑，否则会被跳过）

```bash
rm -rf /autodl-fs/data/RethinkingTMSC_output/Twitter15/Bert/0_output_test
```

然后按第四节手动跑，或重新执行批量脚本。

## 九、常见问题排查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| `No module named 'Code'` | 没设 PYTHONPATH | `export PYTHONPATH=/root/RethinkingTMSC` |
| GPU 0% 但进程在 | 图片特征转换阶段 | 等 1–3 分钟 |
| 找不到 `resnet152.pth` | 权重路径不对 | 传 `--resnet_root /root/RethinkingTMSC/Code/resnet` |
| `FileNotFoundError ... 17_06_4705.jpg` | 兜底图缺失 | 确认 `data/Twitter15/images/17_06_4705.jpg` 存在 |
| faster_rcnn 编译失败 | 服务器 CUDA 12.8 与 torch cu118 不匹配 | 跳过 Faster* 系，不影响其余 150 组 |
| 磁盘满 | 检查点占空间 | 结果在共享盘 `/autodl-fs/data/RethinkingTMSC_output`；系统盘可删 `RethinkingTMSC.zip` 与 `TMSC_env`（Linux 无用） |
| 服务器重启后训练没了 | nohup 进程随关机终止 | 重连后执行 `bash /root/run_server.sh` 续跑（自动跳过已完成） |

## 十、注意事项

- `output/` 是作者原始结果，**不要删**；
- 训练期间别开第二个批量任务；
- 共享盘 `/autodl-fs` 有约 197G 空间，足够存放 150 组结果；
- 服务器按小时计费，跑完或不用时记得关机/释放实例。
